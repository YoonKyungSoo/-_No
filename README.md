# 연차 신청 챌린지

연차 신청 체험(?) 사이트. 사용할 수 있으면 해보시지..

## 스토리
1. 자리에 앉으려는데 의자가 도망감
2. 노트북을 켜려는데 전원 버튼이 도망감
3. 겨우 켰더니 배경화면이 클로즈업되고 태양에서 "뭘 그렇게 멍때리면서 봐?ㅋ"
4. 사내 그룹웨어를 켜려는데 아이콘이 도망감
5. 연차 신청 메뉴 → 날짜 입력 → 신청 버튼이 도망감
6. 겨우 신청 → 신청 중입니다... → **반려** (사유: 윤경수가 싫어함)

## 수정
`app.js`에서 `dodgy(요소, 도망횟수, 대사목록, ...)` 부분의 숫자와 대사를 바꾸면 됩니다.

## 배포
Settings → Pages → Branch `main` / `/ (root)` → Save
